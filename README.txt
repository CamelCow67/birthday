Put her photos in this folder, named to match each gallery slot:

  1.jpg   -> first polaroid ("the day it all started")
  2.jpg   -> second polaroid ("you, mid laugh")
  3.jpg   -> third polaroid ("my favorite view")
  4.jpg   -> fourth polaroid ("us, being ridiculous")
  5.jpg   -> fifth polaroid ("that one perfect trip")
  6.jpg   -> sixth polaroid ("just because")

.jpg or .jpeg both work if you edit the extension in script.js to match,
but .jpg is simplest — just export/save your photos as .jpg with those
exact names and the site will pick them up automatically once you push
them to GitHub. No code changes needed.
